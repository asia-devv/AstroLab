# 🚀 AstroLAb <!--  - Sistema de Monitoramento para Fabricação em missão Espacial -->

  "Print the future. Wherever you are."

O AstroLab é um sistema de monitoramento para fabricação em missão espacial, desenvolvido para resolver o problema da Latência Extrema existente em missões de longa duração. O sistema combina Reconhecimento de Voz, Inteligência Artificial, Visão Computacional e Impressão 3D Inteligente para identificar o problema ou peça  e fabricar de forma autônoma, diretamente no espaço, sem depender de comunicação com a Terra.
